0 · Background: A real-life lockdown incident

On 2026-08-01, the main OpenRouter account of Hermes Agent was suddenlyGoogle, OpenAI, and Anthropic jointly blockade(403violation of provider Terms Of Service). Diagnosis result:

testResultConclusion
OpenAI system (gpt-image-1 / gpt-5-image-mini)403 TOSAccount is permanently flagged (permanently flagged), regardless of IP / credits / settings, retry is invalid
Google system (gemini-3-pro-image / gemini-3.6-flash vision)403 TOS
Anthropic(claude-sonnet-4)403 TOS
z.ai / Qwen / xAI / Meta systemnormalText + image reading is still available

Key lessons:It’s not good to bet all AI capabilities on a single third-party platform. OpenRouter is an aggregator, and once an account is flagged, it will be completely invalid. Rather than opening a new account (with the risks associated with the same IP), move to the infrastructure provider Cloudflare - they are a DNS/CDN provider and will not block you due to "AI content policy".

3 · Tushengtu (hidden skills of FLUX.2)

⚠️ The easiest pitfalls:CF generousflux-2-klein-9bReceive pictures and make pictures, butNot JSON— Pass in JSONimageWill come out400 Type mismatch. Its schema ismultipart/form-data!
# 正確做法：-F multipart，image 用檔案上傳
curl -X POST ".../ai/run/@cf/black-forest-labs/flux-2-klein-9b" \
  -H "Authorization: Bearer $CF_WORKERS_AI_TOKEN" \
  -F "prompt=同一個場景，但女仔而家伏喺沙灘上，golden hour" \
  -F "image=@reference.jpg"        # ← multipart 檔案，唔係 base64！
# → 直接回傳編輯後嘅圖（base64）

This is the most critical discovery of the migration:img2img uses multipart, txt2img uses JSON. Using PythonrequestsJust tiefiles={"image": (name, f, "image/jpeg")} + data={"prompt": ...}.

# config.yaml — 主力：OpenRouter gemma-4:free（26B，免費 :free 唔受三廠封鎖影響）

8 · A collection of pitfalls (all personally tested)

  • 403 TOS is not necessarily a content problem— Even "a red apple" was rejected = blocked at the account level, retry is useless. Instant confirmation with non-Google/OpenAI/Anthropic models (z.ai/qwen/xAI).
  • OpenRouter: free model is not affected by the blockade of the third manufacturer—gemma-4-26b-a4b-it:freeThe best free choice for reading pictures.
  • CF flux-2-klein-9b uses multipart instead of JSON— JSON image will be 400.
  • CF official model list has ≠ used— moondream empty return, llava 400 (Beta); gemma-4 top.
  • Flux fixed output 1024×1024— If you want 4:5 / 16:9, you need to use PIL center cropping (width/height parameters are invalid).
  • deepseek collects pictures but cannot see them— Plain text model; aux vision must explicitly set the vision-capable model.
  • Curl transfers large base64 image "Argument list too long"— Write JSON body and drop it into file for reuse-d @file.
  • Free tier gets 1 parallel request—Batch must add sleep, otherwise it will be queued.

10 · Additional suggestions (from available to production-ready)

The following are additions after review by engineers - focusing on "available → production-ready" details: minimum credentials, retry strategy, cost control, backup depth, and dual-track reconciliation.

10.1 Credential security: Token minimum permissions + Rotation

  • Workers AI Token— "Account → Workers AI → Edit" has the most detailed permissions; if there are multiple projects, it is recommended to openAccount-scoped(Not User-scoped), convenient for revoke without affecting other uses.
  • R2 S3 Token— You can open "Object Read & Write only” (do not use Admin), and set the specified bucket (ai-images)—Even if the token is leaked, it only requires the permissions of one bucket.
  • Rotation strategy— Recommended per90 daysrotation once; multiple CF API Tokens can be opened. The old and new ones can be run in parallel for a while and then the old ones can be deleted without interrupting the service.

10.2 Retry strategy: not related to sleep

If you get 1 parallel in the free tier, you will actually encounter three situations:

situationHTTP StatusHandling suggestions
Rate limit429readRetry-Afterheader, follow him, etc.
Queuing (extremely slow)200Settimeout=60s, timeout is considered a failure fallback
Model is temporarily unavailable500/503Instant fallback to Pollinations without retry
# gen_image.py 加 retry decorator，但 429 唔應該 blind retry
@retry(
    stop=stop_after_attempt(3),
    wait=wait_exponential(multiplier=1, min=2, max=10),
    retry=retry_if_exception_type((
        requests.exceptions.Timeout,
        requests.exceptions.HTTPError
    ))
)

Key points:429 to readRetry-After, otherwise it will be stepped on harder and harder.

10.3 Nonlinear relationship of Flux steps × neurons

§2.1 57.6 neurons is a 4 steps value — steps has a great impact on the cost:

Neuron-saving technique: batch generation (for example, 10 variants at a time), you can use it firststep=1For preview, users choose the best ones first.step=4/8, save a lot of neurons.

10.4 Hidden limitations of Pollinations fallback

  • No key ≠ unlimited— A single IP has an implicit rate limit (about 10 req/min). If it is exceeded, it will return empty or be extremely slow.
  • No SLA— Sometimes it will be down for several minutes, and the fallback logic needs to handle the timeout.
  • Prompt compatibility— weight syntax (e.g.(...:1.2)) may not be supported; it is recommended to keep the prompt simple and not use advanced syntax.

Recommended fallback order:CF flux → Pollinations → Local SD (if any) → Text description instead.

10.5 R2 and Drive dual-track consistency

  • Drive system "write and forget"— Once the upload is successful, it is complete and there is no checksum.
  • R2 can verify— upload for later usehead_objectRead the ETag and compare it with the MD5 of the local file.
# gen_image.py 生成後寫 manifest.jsonl（每行一條，方便日後對賬）
{"timestamp":"...","prompt":"...","drive_id":"...","r2_key":"...","md5":"...","model":"flux-1-schnell","neurons":57.6}

When R2 cleanup deletes old files, it is best to mark them together with the manifestdeleted: true, rather than actually deleting the manifest entry and retaining the audit trail.

10.6 Image metadata: EXIF writing prompt

# 用 PIL 將 prompt、model、timestamp 寫入 PNG 嘅 tEXt chunk
from PIL import Image, PngImagePlugin
img = Image.open("/tmp/cat.png")
metadata = PngImagePlugin.PngInfo()
metadata.add_text("prompt", prompt)
metadata.add_text("model", "flux-1-schnell")
metadata.add_text("generated_at", datetime.utcnow().isoformat())
img.save("/tmp/cat.png", pnginfo=metadata)

In this way, even if the manifest is lost, the original prompt can be read back from the image itself, which is convenient for reproduction.

10.7 The "hidden" endpoint of CF Workers AI: AI binding

The original guide uses the direct API (/ai/run/...). If you have deployed Cloudflare Worker, you can use AI binding:

// worker.js
const response = await env.AI.run(
    '@cf/black-forest-labs/flux-1-schnell',
    { prompt: "..." }
)

Benefits:You can manage tokens (binding uses account permissions), caching, rate limiting, and auth layers.Disadvantages:To deploy workers, there is an additional layer of infra. For Hermes' use case, direct connection to the API is simple enough; but if the API is to be opened for use by multiple people in the future, the binding method will make it easier to manage the quota.

Summary:The fallback should be deep enough. The lessons learned from the OpenRouter factory 3 blockade also apply to CF (free tier has quota, concurrency limit, and sporadic 500).One more layer of backup and one less layer of late-night debugging.
